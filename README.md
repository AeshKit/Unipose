# Unipose

Linux unicode composition in minecraft

This works on any OS, not just Linux

## What ?

So you know how you can do ctrl+shift+u in Linux to specify a UTF hex code ? Very fun for troling the hell out of your programming buddies if you've memorized the lookalikesː

![Putting u2d0 in place of ':'](https://raw.githubusercontent.com/AeshKit/Unipose/gallery/Screenshot_20260910_192402.png)
![Wow, unreadable error](https://raw.githubusercontent.com/AeshKit/Unipose/gallery/Screenshot_20260910_192500.png)

I actually replaced two symbols with lookalikes, not just the colon. Pretty effective innit ?

Anyways, some people actually find this useful since they can type characters that aren't on AltGr without changing keyboard layouts. For some reason though this just doesn't work in minecraft, so I've implemented it into minecraft itself.

![I want my B to look like в with u432](https://raw.githubusercontent.com/AeshKit/Unipose/gallery/b.png)

Yes, this means that you can use Linux unicode composition in Minecraft on WindowsOS and MacOS, although this is ultimately useless in Windows as the numpad thing apparently works.

I'll add more features, like a preview and config if this mod gets any traction. Should be simple to keep updated so I'll do my best with that.

## Installation

Grab the latest jar from [releases](https://github.com/AeshKit/Unipose/releases), and put it into your /mods/ folder. Once approved, this mod will also be available on Modrinth and Curseforge.

This mod only depends on Fabric API. Besides that, there are no dependencies [ yet ].
